# New installs start with computer control and meeting notes off, and auto-sleep on

Pip is published for any Omarchy user, so a fresh install must not click or type on the desktop, record whole sessions, or keep a paid brain billing by surprise. New installs default to computer control off (one-tap opt-in with a warning), meeting notes off, and auto-sleep after 5 minutes without speech. Existing installs keep their saved settings. Gemini Live (free tier) is the default brain; talking out loud is on.
